# Как запустить бота на сервере (чтобы работал без открытого терминала)

Бот должен крутиться на компьютере или сервере, который **всегда включён и в интернете**. Ниже — три варианта.

---

## Вариант 1. Арендовать VPS (сервер в интернете)

**Что нужно:** небольшой Linux-сервер (1 ядро, 512 МБ–1 ГБ RAM). Платно, обычно от 100–300 ₽/мес (Timeweb, Selectel, DigitalOcean, Beget и т.п.).

**Шаги:**

1. **Купить VPS** с Ubuntu (22.04 или 24.04). При создании указать SSH-ключ или пароль для входа.

2. **Подключиться по SSH** с вашего ПК — это способ «зайти» на сервер с вашего компьютера и управлять им с клавиатуры.

   **Зачем это нужно:** VPS — это чужой компьютер в интернете. На нём нет экрана и мышки. Чтобы что-то на нём установить или запустить, вы подключаетесь к нему по сети. Такой способ входа и называется SSH: вы открываете на своём ПК «терминал» (командную строку), вводите одну команду — и дальше все команды, которые вы печатаете, выполняются уже на сервере, как будто вы сидите за ним.

   **Как сделать на Windows:**

   - Откройте **PowerShell** или **Командную строку** (поиск в меню Пуск: «PowerShell» или «cmd»).
   - Вместо `IP_АДРЕС_СЕРВЕРА` подставьте тот IP, который выдал хостинг после создания VPS (числа через точки, например `185.123.45.67`). Логин чаще всего `root`. Команда будет такой:
     ```bash
     ssh root@185.123.45.67
     ```
   - Нажмите Enter. В первый раз спросят «Trust this host?» — напишите `yes` и Enter.
   - Попросят пароль — введите пароль от сервера (тот, что вы задали при создании VPS или который прислали в письме). При вводе пароля символы не отображаются — это нормально, введите и нажмите Enter.
   - Если всё верно, вы увидите приглашение вроде `root@server:~#` — значит, вы уже «внутри» сервера. Дальше все команды из инструкции выполняйте там.

   **Если команда `ssh` не найдена:** в Windows 10/11 можно включить встроенный SSH: «Параметры» → «Приложения» → «Дополнительные компоненты» → «Добавить компонент» → найти «Клиент OpenSSH» и установить. Либо скачайте [PuTTY](https://www.putty.org/): в поле Host name введите IP сервера, Connection type — SSH, нажмите Open; логин `root`, пароль — когда попросит.

3. **Установить Python и зависимости:**
   ```bash
   apt update && apt install -y python3 python3-pip python3-venv
   ```

4. **Загрузить проект на сервер:**
   - Через Git: `git clone ...` (если код в репозитории), или
   - Скопировать папку `photoimpuls-bot` через FileZilla / WinSCP (протокол SFTP, тот же логин/пароль что и SSH).

5. **На сервере создать виртуальное окружение и установить зависимости:**
   ```bash
   cd photoimpuls-bot
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

6. **Создать файл `.env`** на сервере (в папке `photoimpuls-bot`) с теми же переменными, что у вас локально: `BOT_TOKEN`, `CHANNEL_ID`, `YANDEX_DAY1_LINK`, `YANDEX_DAY2_LINK`, `YANDEX_DAY3_LINK`, `ADMIN_IDS` и т.д.

7. **Запустить бота как службу**, чтобы он перезапускался после перезагрузки сервера:
   ```bash
   sudo nano /etc/systemd/system/photoimpuls-bot.service
   ```
   Вставить (путь `/home/ubuntu/photoimpuls-bot` замените на свой):
   ```ini
   [Unit]
   Description=Telegram bot photoimpuls
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=/home/ubuntu/photoimpuls-bot
   ExecStart=/home/ubuntu/photoimpuls-bot/venv/bin/python bot.py
   Restart=always
   RestartSec=10

   [Install]
   WantedBy=multi-user.target
   ```
   Сохранить (Ctrl+O, Enter, Ctrl+X). Затем:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable photoimpuls-bot
   sudo systemctl start photoimpuls-bot
   sudo systemctl status photoimpuls-bot
   ```
   Если статус `active (running)` — бот работает. Логи: `sudo journalctl -u photoimpuls-bot -f`.

**Итого:** бот крутится на VPS постоянно, терминал на вашем ПК можно закрыть.

## Вариант 2. Облачный хостинг для приложений (PaaS)

**Что нужно:** аккаунт на одном из сервисов (Railway, Render, PythonAnywhere и т.п.). Часто есть бесплатный тариф с ограничениями.

**Общая идея:** вы «заливаете» проект (через Git или архив), в настройках указываете переменные окружения (`.env` в виде ключей/значений) и команду запуска: `python bot.py`. Сервис сам держит процесс включённым и перезапускает при падении.

**Пример для Railway:**
1. Зарегистрироваться на [railway.app](https://railway.app).
2. New Project → Deploy from GitHub (или загрузить папку).
3. В Variables добавить: `BOT_TOKEN`, `CHANNEL_ID`, `CHANNEL_INVITE_LINK`, `YANDEX_DAY1_LINK`, `YANDEX_DAY2_LINK`, `YANDEX_DAY3_LINK`, `ADMIN_IDS`.
4. Команда запуска: `pip install -r requirements.txt && python bot.py` (или указать в настройках сервиса).

**Плюс:** не нужно настраивать сервер вручную. **Минус:** бесплатные тарифы могут «засыпать» или ограничивать время работы — для бота лучше проверить условия.

## Вариант 3. Ваш компьютер (Windows), если он всегда включён

Если бот будет работать на вашем ПК и вы готовы не выключать его:

- **Запуск в фоне без окна:**  
  Создать файл `start_bot.vbs` в папке с ботом с содержимым:
  ```vb
  Set WshShell = CreateObject("WScript.Shell")
  WshShell.Run "py bot.py", 0, False
  ```
  Запускать двойным щелчком по `start_bot.vbs` — окно терминала не появится, бот будет работать в фоне. Остановить можно через «Диспетчер задач» (найти процесс `python` и завершить).

- **Автозапуск при включении ПК:**  
  Положить ярлык на `start_bot.vbs` в папку автозагрузки: `Win+R` → `shell:startup` → Enter.

**Минус:** при выключении или перезагрузке ПК бот остановится; для «сервера» надёжнее VPS или PaaS.

---

## Что выбрать

- **Нужна стабильная работа 24/7** — арендовать **VPS** (вариант 1) и запустить бота службой.
- **Хочется без возни с сервером** — попробовать **PaaS** (вариант 2), проверив, что боты не отключаются на бесплатном тарифе.
- **Только чтобы не держать терминал открытым и ПК всё равно всегда включён** — **ваш ПК** (вариант 3) с запуском через `start_bot.vbs` и при желании автозагрузкой.

После того как выберете вариант (например, VPS с Ubuntu), можно расписать шаги под ваш хостинг (где покупали сервер, как зайти по SSH и куда положили папку `photoimpuls-bot`).
