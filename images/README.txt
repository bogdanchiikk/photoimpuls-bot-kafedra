Картинки для бота — положите сюда файлы и укажите пути в .env:

- добро пожаловать.jpg — при /start
- подт подписку.jpg — подтвердить подписку
- специальность.jpg — выбор специальности
- указать день.jpg — Фото-Центр, выбор дня
- расписание конгресса.jpg — расписание конгресса

В .env:
WELCOME_IMAGE=images/добро пожаловать.jpg
IMAGE_SUBSCRIBE=images/подт подписку.jpg
IMAGE_SPECIALTY=images/специальность.jpg
IMAGE_PHOTO_CENTER=images/указать день.jpg
IMAGE_PROGRAM=images/расписание конгресса.jpg
